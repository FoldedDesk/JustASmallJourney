# 特殊搭配攻略（离线文档）

适用于 V0.7。本文供开发与离线查阅，不在游戏页面展示，也不由游戏静态资源目录提供。

## 触发规则

- 出发时，服务器先按装备倾向随机抽取目的地，再检查食物与工具，并保存命中的搭配快照。玩家不能直接指定地点，概率见[目的地概率说明](目的地概率说明.md)。
- 实际抽中下表地点且携带条件满足时必定触发，不再进行第二次概率判定；仅带齐行囊不能保证前往该地点，要求指定工具的组合必须带齐工具。
- 每次只命中一套搭配；若同时命中，优先使用要求指定工具的一套。
- 回家时获得当地基础纪念品、搭配专属纪念品，以及一张主题明信片。工具的额外当地纪念品效果仍可生效。
- 食物消耗 1 份，工具不消耗。未命中搭配时按普通旅行结算。
- 重复旅行可以再次获得奖励；刷新或重启不会重复结算同一段旅行。
- 玩家页面只展示正常旅行选择与归来后的故事、纪念品，不预告配方、命中状态、主题清单或攻略。

## 内容维护

配方与故事定义在 [content.py](../content.py)，服务器结算在 [app.py](../app.py)。调整配方时同步更新本表；已经出发的旅行沿用出发时保存的快照。

本攻略不应复制到 `src/` 或 `dist/`，也不通过 `/api/state` 下发。API 仅返回旅行实际携带的食物和工具，以及已经获得的明信片故事和奖励。
