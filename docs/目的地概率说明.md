# 目的地概率说明（离线参考）

这是《小小远行》自己的暂定数值，不是《旅行青蛙》的官方概率。仅供本地策划和开发查阅，不在前端展示或下发。

## 如何决定目的地

玩家只选择一份食物与一件可选工具，信物暂未开放。点击出发后，服务器为十个地点各设 **10 点基础权重**，再叠加食物和工具影响，按最终权重随机抽取一个地点。

- 食物：偏好的两个地点各 **＋30**；饭团不增加倾向。
- 工具：偏好的两个地点各 **＋10**；不带工具则不加分。
- 重叠时直接相加，所有地点始终可达。
- 概率＝该地点权重÷所有地点权重之和。地点只抽取一次并保存，刷新、重启或改变页面选项不会重抽。
- 不接受客户端指定目的地；信物目前也不能通过接口携带。

## 大致概率示例

| 行囊 | 概率 |
| --- | --- |
| 饭团，不带工具 | 十个地点各 10% |
| 热可可，不带工具 | 雪原、山谷各 25%；其他地点各约 6.25% |
| 柠檬汽水＋相机 | 海岸约 27.8%、沙丘约 22.2%、山谷约 11.1%；其余各约 5.6% |
| 饭团＋相机 | 海岸、山谷各约 16.7%；其他地点各约 8.3% |

短期连续去同一地点是正常随机结果，当前没有保底或防重复规则。

## 与隐藏搭配、偶遇的关系

抽中目的地之后，再检查[特殊搭配攻略](特殊搭配攻略.md)里的条件。带齐食物和工具只是提高机会，**只有实际抽中对应地点，才会触发该地点的搭配奖励**。

旅行期间，自己的状态、好友状态和出发动态不公开目的地。偶遇记录在服务器生成，世界偶遇动态等双方归来后才公开；各自归来时收到自己的明信片。已经归来的朋友可能从共同明信片推知同行者去过哪里，这是共同回忆的自然结果。

规则实现：`content.py` 中的 `FOOD_DESTINATIONS`、`TOOL_DESTINATIONS`、`destination_weights()`；出发与保存位于 `app.py`。调整数值后请同步更新本文。
