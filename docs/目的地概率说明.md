# 目的地概率说明（离线参考）

这是本游戏的暂定规则，不是《旅行青蛙》的官方概率；不会在前端展示或下发。

目前 50 个目的地，每个基础权重为 10。食物偏好的两个地点各加 150，工具偏好的两个地点各加 50；饭团无偏好。重叠相加，概率＝地点权重÷总权重，所有地点都能抵达。

扩展地图后同步调整了倾向强度：食物加分＝地点数×3，工具加分＝地点数。无保底、无防重复，不接受客户端指定地点。信物现已开放，不直接改变目的地权重；具体作用见[工具与信物说明](工具与信物说明.md)。路线抽取一次后入库存档。
