# 小小远行 · JustASmallJourney

一个慢慢长大的朋友旅行小世界。当前内容：60 种食物、50 个目的地、100 种纪念品、20 种工具、100 款风景明信片与 50 款隐藏搭配故事，以及种植、兑换、旅行与收藏循环。

仓库：https://github.com/FoldedDesk/JustASmallJourney

## 本地运行

需要 Python 3.10+ 和 Node.js 20.19+。

```sh
./start.sh
```

首次运行会安装依赖并构建页面。打开 http://127.0.0.1:8000 。退出服务按 Ctrl+C；再次运行后原存档仍在。

如需换端口：`PORT=8001 ./start.sh`。

## 当前玩法

1. 在“初次入住”注册账号（密码至少 8 位），从五种动物中选择一只，填写最多 16 字的名字。
2. 点击出门打开行囊弹窗，选择一种食物、一件可选工具与一枚可选信物。目的地由服务器按食物和工具倾向随机抽取，不接受玩家指定，归来拆信时才揭晓。
3. 旅程随机分为附近散步、悠闲漫游、小小远行，基础时长分别为 60、120、180 秒；部分工具、信物可缩短时长。时长与目的地独立，离开网页不影响进度。
4. 食物会在出发时消耗，工具不会消耗。点击小院或室内的背包，会在当前页面打开弹窗，通过“食物”“工具”“信物”子选项查看库存。每日饭团仅在尚未领取时显示，领取后自动隐藏。关闭按钮、Esc 或点击弹窗外侧均可关闭，返回原场景并恢复入口焦点。
5. 返回时生成一张明信片，包含动物、地点、短文、带回的纪念品和日期；纪念品会进入收藏页的礼物图鉴。
6. 在“朋友世界”把旅行带回的纪念品送给朋友的小动物，并查看最近赠礼记录；“收藏”页可展开礼物图鉴。
7. 在小屋拆开新来信，或在明信片页回看所有旅行。
8. 两位朋友去同一地点，旅行时段重叠时必定偶遇。双方各自在回家时额外获得一张共同明信片和同行纪念章；一个旅程组合只记录一次偶遇。
9. 在“朋友世界”查看其他动物的状态、出发、偶遇与赠礼动态，页面每 10 秒更新。旅行期间自己与好友的状态都不公开地点，出发动态也不写地点；偶遇动态等双方归来后公开。
10. 全体玩家共享每日虚构天气（晴朗、多云、小雨、微风），按服务器时区的日期更新；四季按北半球月份划分。天气会影响旅行短文，雨天或微风天带热茶还有专属见闻。出发天气随旅行保存，明信片保留当天的天气与季节，跨天结算不改变回忆；旧旅行不补造天气。
11. 小院支持摸动物、开关灯与照料花朵；点击邮箱、背包、路牌可打开对应功能。归来后打开明信片，可以探索旅途场景中的三处小物件，50 个地点共 150 处见闻。新地点共享十类 SVG 插画背景，配独立故事与互动；并非 50 张独立绘制的背景。点景物是即时氛围反馈，关闭后重置；支持键盘与减少动态效果偏好。
12. 三块草圃直接放在院子场景里，点空地免费播种，点成熟地块收获。每块默认 5 分钟成熟，收获 6 三叶草。离线生长、成熟不枯萎，但不会自动累积第二轮；收获后可以重新播种。新老玩家首次布置草圃均赠 12 三叶草，只发一次。余额和种植进度保存在服务器。
13. 点院子里的小摊打开旅行小铺弹窗，不再进入独立页面；从行囊补货后可以返回原行囊。全部 60 种食物每份 2～6 三叶草；20 种工具只需拥有一件，新增 16 种可花 12～18 三叶草兑换，原四件仍为新手装备。工具不可重复购买；兑换扣款与入库在同一事务完成，同一请求重试不会重复扣款。小铺支持食物、工具、信物分类，搜索和每页 12 件。原有每日饭团补给保留。
14. 食物、地点与工具可以触发隐藏的主题故事和专属纪念品。游戏不展示配方手帐、一键搭配、出发前命中提示或明信片触发配方，由玩家在旅行中发现。配方与命中快照不通过状态接口下发；服务器继续按原规则结算并保留出发时的快照。
15. 明信片页保留已经收到的故事、标题与纪念品。赠送最后一件纪念品后，图鉴仍保留首次获得记录。
16. 基础 65% 的旅行会在半程捎来一句不透露地点的问候，部分工具与信物可提高机会。来信在出发时保存，到时间后才展示；离线期间错过的信会留在旅行日记中。
17. 新旅行归来后，小院里出现行李；点击行李或动物查看这次明信片和纪念品。奖励在归来时已经入账，拆行李只确认展示，不重复发奖。旧版本的旅行沿用已看过的状态，不补出待拆行李。
18. “日记”按出发日期分组，保存出发、途中来信、归来和偶遇回忆，可重新打开相关明信片。旅行中不显示目的地；日记和行李仅本人可见。

19. 小动物在家时每五分钟切换读书、打盹、喝茶或整理行李。点院子里的门进入室内，点书桌、床铺或茶杯可让动物移动到相应位置；窗帘和台灯可切换。出门期间屋内为空，仍可整理床铺。墙上的纪念品架提供三个持久展示位，可回看首次获取来源；送出最后一件时自动收起，不删除图鉴记录。室内还可打开背包、归来行李，点门返回院子。灯光、窗帘与临时活动为当前场景状态，不写入存档。
20. 行囊可点选装入、取下食物、工具和信物，带好食物才可出发；成功后播放简短告别。背包、行囊、摆设与收藏支持搜索，收藏支持地点筛选和分页。
21. 六种信物可兑换、永久使用，新老玩家各免费获一枚四叶草。工具在原有基础上增加时长、途中来信、三叶草及食物返回等作用；出发时保存效果，归来明信片说明实际收获。奖励只发一次，旧进行中旅行沿用旧效果。数值见[工具与信物说明](docs/工具与信物说明.md)。

完整配方仅在 [特殊搭配攻略（离线文档）](docs/特殊搭配攻略.md) 中整理，内容定义在 `content.py` 和 `expansion.py`。完整数量与目录见 [内容目录](docs/内容目录.md)；用 `rtk proxy .venv/bin/python scripts/export_content_docs.py` 同步离线参考。
装备对目的地的倾向、权重和大致概率见 [目的地概率说明（离线文档）](docs/目的地概率说明.md)，前端不展示数值。

最多允许 15 个账号。每个账号有独立的动物、旅行与收藏，登录保持 30 天；退出后会话立即失效。用户名忽略 ASCII 大小写，不允许重名。密码以独立盐值的 PBKDF2-SHA256（600,000 轮）哈希保存，会话令牌仅以哈希存入数据库；浏览器使用 HttpOnly、SameSite Cookie。注册和登录合计按来源地址限制为每 15 分钟 30 次。

同一浏览器的标签页共享登录；模拟两位朋友请用不同浏览器或独立浏览器配置。没有邀请注册、密码找回或公网部署配置，服务默认仍只监听本机。正式邀请朋友前，应先完成邀请入口、HTTPS 与部署配置；HTTPS 下设置 `JOURNEY_SECURE_COOKIE=1`。

## 从单人版本升级

首次运行新版本时，如存在旧版数据表，会在同目录自动创建 `journey.sqlite3.v1-backup`。旧表保留不动，新版本使用独立的数据表。

如果旧存档有动物，第一个注册账号必须勾选“将原来的小动物与旅行回忆保存到我的账号”。注册成功后，动物、已完成及进行中的旅行、明信片文字与已读状态会一起复制到这个账号。未勾选时不会创建账号，也不会丢弃旧小屋。请由旧小屋的主人完成首次注册后，再邀请其他人入住。

迁移事务失败会整体回滚，原始表和升级前备份均保留。后续重启不会重复复制。

## 开发

前端 Vue 3 + Vite，后端 FastAPI，数据使用 SQLite。

```sh
# 终端一：后端
.venv/bin/python -m uvicorn app:app --reload --host 127.0.0.1 --port 8000
# 终端二：前端，API 自动代理到后端
npm run dev
```

存档默认位于 `data/journey.sqlite3`，已排除在 Git 之外。停止服务后复制此文件即可备份，恢复时停止服务再放回原位。`JOURNEY_DB` 可以指定独立存档路径，`JOURNEY_DURATION_SECONDS` 可以调整旅行时长，`JOURNEY_GROW_SECONDS` 可以调整新播种作物的成熟时间（默认 300 秒）。

旅行按服务器时间在读取状态时结算；即使服务中途关闭，重新启动并访问时也会补结算。数据库事务及唯一约束保证每次旅行仅生成一张普通明信片、每个偶遇向每位参与者仅发放一张同行明信片，并禁止同一动物同时出发两次。旅行奖励通过独立发放记录进入背包，刷新和重启不会重复发纪念品。赠礼会从送礼者库存扣除，并通过独立发放记录加入收礼者库存。动物名字与参与者在偶遇发生时保存快照。
